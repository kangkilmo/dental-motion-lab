A CLEARER WAY TO PRACTICE

무엇을, 어떻게 볼까요.

점수의 의미와 한계를 먼저 투명하게 알려드립니다.

01

먼저, 30초 데모

‘동작 연습’에서 시작을 누르면 가상 마커가 경로를 따라 움직입니다. 빠른 움직임이나 추적 손실 시나리오를 골라 피드백이 어떻게 달라지는지 확인하세요.

02

펜과 색 테이프 준비

카메라를 고정하고 펜 끝에 밝은 색 테이프를 붙이세요. 카메라 연결 뒤 ‘마커 색 선택’을 누르고 화면의 테이프를 클릭하세요. 화면 속 경로에 연습 도구를 맞춥니다.

03

나만의 기준 경로

기준 경로를 직접 그리거나 JSON 파일로 공유할 수 있습니다. 실제 술기 경로는 교육자가 정해야 합니다. 경로·허용 폭·시간이 같은 세션끼리만 변화량을 비교합니다.

04

관찰이 충분할 때 평가

12초 이상 연습, 유효 동작 8초 이상, 추적 가능 시간 65% 이상, 경로 커버리지 30% 이상일 때만 종합 점수를 표시합니다. 정지·가림·색상 혼동 구간은 동작 점수에서 제외합니다.

평가 기준

종합 점수 = 경로 정확도 40% + 속도 적합도 25% + 경로 커버리지 20% + 움직임 안정도 15%. 실시간 점수와 최종 점수에 같은 계산을 적용합니다.

경로 정확도
펜 끝과 기준 경로 사이의 2D 거리입니다. 허용 폭의 두 배 이상 벗어나면 해당 시점은 0점입니다.
속도 적합도
화면 너비 기준 초당 0.08~0.28 범위를 기본 목표로 사용합니다. 이는 연습용 설정이며 임상 표준 속도가 아닙니다.
움직임 안정도
짧은 시간의 속도 벡터 변화를 이용한 대리 지표입니다. 카메라 잡음과 빠른 방향 전환에 영향을 받습니다.
경로 커버리지
32개 경로 구간 중 허용 폭 안에서 움직임이 관찰된 구간의 비율입니다.
시간 가중 평가
프레임 수 대신 실제 시간 간격으로 평균을 계산합니다. 0.2초를 넘는 관찰 공백은 연결해 평가하지 않습니다.

이 점수는 치과 술기 자격이나 진단 결과가 아닙니다.

화면 속 2D 위치만 관찰합니다. 접촉 압력, 실제 치아 표면, 깊이, 3D 기구 각도, 손가락 지지점 및 임상 효과를 측정하지 않습니다. 서로 다른 카메라 거리·각도에서 나온 점수도 직접 비교할 수 없습니다.
